With Digital Carrot 1.7 Mac and Windows are now out of beta!

## Web Browser Support

Digital Carrot desktop now supports:

- Firefox
- Chrome
- Edge
- Opera
- Brave
- Safari

## Better Stability and Performance on Desktop

Performance has been optimized on Desktop so that Digital Carrot requires less RAM and CPU to run while in the background.
